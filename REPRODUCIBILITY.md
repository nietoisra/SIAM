# Reproducibility Statement

This repository supports reproducible system-level validation of inertial gait-analysis pipelines.

- All preprocessing parameters are fixed a priori.
- No subject-specific tuning or post-hoc optimization is performed.
- Validation is performed exclusively using leave-one-subject-out (LOSO).
- Random seeds are fixed to ensure deterministic behavior.
- Reported metrics describe architectural behavior under adverse validation conditions.

This repository is intended for methodological research and educational use.
